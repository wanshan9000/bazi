# 五运六气 · 健康养生

## 适用场景

五运六气（健康养生）：按出生年干支推中运（太过/不及）、司天在泉、主气六步、客气加临、客运，按属相判六大体质（牛羊湿/鼠马热/虎猴火/兔鸡燥/龙狗寒/蛇猪风），给出体质健康风险与饮食作息情志养生建议。仅做体质分析与生活调养建议，不做医疗诊断。问"五运六气""我的体质""养生调理""健康风险"时使用。
