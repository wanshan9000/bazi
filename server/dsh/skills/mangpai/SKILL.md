## 第一阶段：预处理

### 基础排盘与校准

- 四柱：年柱以立春为界，月柱以节令为界（工具已处理）。
- 胎元：月柱天干顺推一位、地支顺推三位。
- 命宫：以月令支起子时逆数至出生时支；身宫：顺数至出生时支。
- 日柱空亡：六甲旬查表（见下）。
- 真太阳时：出生地经度校正。
- 月令当令之神：判司令深浅。

### P0—P3 筛查（快速锁定太极点）

| 优先级 | 特征 | 判定方法 |
|:---:|:---|:---|
| **P0** | 有无天克地冲 | 年/月/日/时柱之间，或与日主直接对冲 |
| **P1** | 有无三合 / 三会局 | 三合（申子辰等）、三会（寅卯辰等） |
| **P2** | 有无虚神拱夹 | 三地支缺中间字（寅戌拱午） |
| **P3** | 日柱是否空亡 | 六甲旬查表 |

判定规则：P0 有冲先论冲；P1 有合局，冲合并存时合能解冲，先合后冲。

### 空亡（六甲旬查表法）

口诀：**甲子戌亥空，甲戌申酉空，甲申午未空，甲午辰巳空，甲辰寅卯空，甲寅子丑空。**

- 日柱地支坐空亡：日主精力尚可，但空亡填实之年集中爆发。
- 做功目标坐空亡：目标虚悬，逢填实流年才得。
- **填实为应，空亡亦为应**：真空亡流年往往最是陷阱之年（看似稳，实则最易破财）。

## 第二阶段：结构定性

### 宾主界定（四层）

| 层次 | 主（我） | 宾（外界） |
|:---|:---|:---|
| 第一层 | 日干 | 其他干支 |
| 第二层 | 日柱（我和配偶） | 其他三柱 |
| 第三层 | 日时柱（我家：家庭、晚年、核心资产） | 年月柱（家外：单位、社会关系、原生家庭） |
| 第四层 | 四柱八字 | 大运流年 |

四重嵌套：日支（我身之根基）→ 日干 + 时柱（我之意志与产出）→ 月柱（社会舞台与事业）→ 年柱（大环境与祖上）。

- 官在主位 = 我的官；财在宾位 = 财跑出去了。
- 宾星入主宫 = 外界资源落到自己身上；主星跑到宾位 = 自己的资源被外人分走消耗。
- 做功方向：从宾向主 = 从外界获取；主宾同动 = 主动出击。核心法则："用我主位之体，制宾位之用，功归自己"。

### 体用定义

| 分类 | 包含 | 说明 |
|:---|:---|:---|
| **体（工具）** | 日主、比肩、劫财、禄、印星、食神、伤官 | 我自己以及我可以直接调动、依靠的力量 |
| **用（目标）** | 正财、偏财、官杀（伤官略偏于用） | 我人生想要达到的目标 |

"体"若闲着不做事，必无事生非成差命；财官必须与"体"发生关系方能有作为。

- **贼神与捕神**：主 / 体特别旺而宾 / 用特别弱时，旺方为捕神（警察），弱方为贼神（小偷）。捕神太旺喜贼神出现，一出现正好被抓住而体现价值；制得干净喜贼神现。
- **正用**：主位是体、宾位是用，用主位之体制宾位之用；**反用**：主位是用、宾位落了体。
- **正局**：大运做功方向与原局一致；**反局**：与原局相悖，破坏原局结构。

### 势力与气象

盲派看"势"不看旺衰：五行是否结成方阵、是否有合力、是否流通。筛查三会（寅卯辰等）、三合（申子辰等）、六合、六冲、三刑是否成立。

| 类型 | 条件 | 格局上限 |
|:---|:---|:---|
| 有势有功 | 三会 / 三合成形 + 做功成立 | S 级·顶级 |
| 有功无势 | 做功成立但无大局 | A/B 级 |
| 有势无功 | 局成但无做功通道 | 普通 |
| 无功无势 | 散局无合力 | C/D 级 |

> 有势没有功，到老一场空；有功没有势，辛苦活一世。没功也没势，就是差八字；有势又有功，定是富贵翁。

### 入手分析（传统五步备查）

1. 日干是否有合？日干合官或合财，这两样是命主追求的东西，能否实现看这个合的功。
2. 日干是否有生的十神？食伤同样是命主追求的东西，看食伤在局中的功。
3. 日支是否成党有势？日支与同五行地支结成势力。
4. 日支是否与其它支发生作用？刑冲克害墓合暗合，只要有关系即视为做功。
5. 判定做功主体：

| 情况 | 以谁为主 |
|:---|:---|
| 日干参与做功 | 日干 |
| 日干没做功，日支参与做功 | 日支 |
| 干、支都参与做功 | 日柱 |
| 干、支都没有做功 | 继续看禄神与比劫位置 |

找到做功的那一个（或几个）柱位作为功神，以它为核心分析命局。

### 合（柔性做功）

> 合比冲更高级：冲是硬抢，合是智取。合代表谈判、绑定、协议、合作、占有。

| 类型 | 组合 | 定性 |
|:---|:---|:---|
| 天干五合 | 甲己、乙庚、丙辛、丁壬、戊癸 | 合象即捆绑：人事关系的绑定（合作、婚姻、结盟、利益交换） |
| 地支六合 | 子丑、寅亥、卯戌、辰酉、巳申、午未 | 合绊 + 合化：合绊锁住对方，合化转化能量 |

| 作用 | 定义 | 现实翻译 | 效率 |
|:---|:---|:---|:---|
| **合制** | 用"体"合"用"，把对方完全制住 | 技术入股锁死项目、婚姻绑定资源、协议锁定客户 | 高 |
| **合绊** | 双方互合，彼此锁住 | 协议签了但执行拖拉，合作中扯皮 | 中 |
| **合化** | 合后五行转化成第三种能量（需化神有根） | 资金 + 技术 = 新项目，名 + 利 = 权 | 高 |

铁则：
1. **合看宾主定得失**：合在宾位（年月）= 主动去外界绑定资源；合在主位（日时）= 已握在手心，无需外求。
2. **合怕冲，冲则破局**：原局有合、流年遇冲，绑定的关系 / 协议在当年被撕开；可能是解套，也可能是毁约。
3. **双合力量翻倍**：两个同字合一个目标字 = 对该目标"死磕"；正向志在必得，反向孤注一掷。
4. **实合做功，虚合空谈**：合的两方都须有根气；一方无根只是口头协议，无功。

干合支合联动：天合地合（日主合年干财 + 日支合年支财）= 深层利益捆绑难脱离；天合地冲 = 貌合神离；天地双合（两柱互合）= 宿缘深厚，但合死则无变通。

### 六冲（核心做功）

> 传统派视冲为凶险；盲派把冲视为最高效的做功手段。冲不是目的而是手段：冲得动、冲得开、冲得对，就是得财得官。

冲的本质：**动**（跳槽、搬家、出差）、**换**（宾位的东西被冲到主位，以资源换财）、**开**（墓库被冲则开：资产解冻、资金释放）、**撞**（竞争、谈判、官司）。口诀：不冲不发，不撞不获。

| 冲 | 五行 | 本象 | 效率 |
|:---|:---|:---|:---:|
| **辰戌冲** | 土冲土 | 湿土冲燥土，库对库；财富 / 权力的总开关 | 最高·库冲 |
| **丑未冲** | 土冲土 | 库对库，两库同开、交换资源 | 最高·库冲 |
| 子午冲 | 水克火 | 寒热交替、季节颠倒；思想冲突、泡沫破裂 | 中·气冲 |
| 卯酉冲 | 金克木 | 门窗对刀斧；场所变动、手术、切割 | 中·气冲 |
| 寅申冲 | 金克木 | 驿马对冲；奔波、迁移、跨界、物流 | 中·气冲 |
| 巳亥冲 | 水克火 | 驿马 / 门户对冲；出国、跨行业、被外界推着走 | 中·气冲 |

做功机制（不看旺衰，只看谁冲谁、冲什么）：

| 冲的方向 | 结果 |
|:---|:---|
| **主位冲宾位**（日时冲年月） | **得**：我去外面拿别人的东西，功归自己 |
| **宾位冲主位**（年月冲日时） | **失**：外部压力冲击我的根基，被动 |
| **主位自冲**（日支与大运同字对冲） | **内耗**：决策反复、身体暗损、家庭摩擦 |
| **体冲用**（比劫冲财、食伤冲杀） | **得**：用我的资源冲目标 |
| **用冲体**（财冲印、官冲身） | **压力**：有波折但未必坏 |

- **冲开 vs 冲散**：被冲之字有根气（实根或库根）→ 开而不散，得财得官，越冲越有；无根或根极弱 → 散而不聚，破财损官。
- **库冲秘法**：墓库平时闭锁，只有被冲时库门才开。辰戌冲开水库与火库（辰藏乙癸戊、戌藏辛丁戊），丑未冲开金库与木库（丑藏癸辛己、未藏丁乙己），取出的十神依日主而定。
- **力度倍增**：单冲（1:1）开库一次；**双冲**（两同字冲一字或对冲各二）力度翻倍、财富量级跃升；三冲（3:1）颠覆性变化，伴随巨大风险。
- **冲的代价**：冲 + 刑（如辰戌冲兼辰辰自刑）财到手但决策反复内耗；冲 + 穿（如辰戌冲兼卯辰穿）开大财的同时才华精力被消耗；冲 + 合（如辰戌冲兼卯戌合）刚柔并济，硬冲求财与柔性绑定并行，功最大；冲 + 伏吟：事情两头牵扯，力度被拉长。口诀：冲带刑，财到手也难安；冲带穿，利到三分损一分；冲带合，刚柔并济功最大。

> 盲派看冲不看克，冲是功来不是祸。主冲宾来得外财，宾冲主来受逼迫。库冲开库取珍宝，气冲换地动奔波。双冲三冲力度大，制尽制不尽看根脚。冲带刑穿有代价，冲合交加最灵活。流年应期冲为上，逢冲而动莫蹉跎。

### 六穿（暗损做功）

> 穿比冲更毒：冲是明着来（可防），穿是暗着来（难躲）。

| 穿 | 本质 | 取象 |
|:---|:---|:---|
| 子未穿 | 财与食伤互穿，财到手即损 | 投资易亏；胃、乳腺、脾脏 |
| 丑午穿 | 财星 / 名誉被暗中玷污 | 投资被坑、名声受损、财务暗耗 |
| 寅巳穿 | 才华被压制，方案被否 | 职场被穿小鞋、创意被剽窃 |
| **卯辰穿** | 才华消耗身体根基 | 腰骶椎、肾、泌尿系统；婚姻暗斗 |
| 申亥穿 | 印星被穿，靠山靠不住 | 贵人变小人、学历资质失效 |
| 酉戌穿 | 财库被暗破 | 暗耗钱财、税务纠葛 |

| 作用 | 定义 | 代价 |
|:---|:---|:---|
| **穿制（有功）** | 用"体"穿"用"，暗中制住对方（如卯木穿辰中戊土官杀 → 解决压力、摆平小人） | 杀敌一千自损八百，精力透支 |
| **穿伤（有灾）** | 宾位穿主位，外部伤害内部（如月支丑穿日支午 → 事业压力穿透身体） | 健康损伤、婚姻摩擦、情绪耗竭 |

铁则：
5. **明冲易躲，暗穿难防**：穿是阴面做功，伤害隐蔽、持续、令人疲惫。
6. **穿能制杀，但代价极大**：命局带穿者做任何事都比别人多付三分成本。
7. **穿怕合，合则止穿**：流年合住穿害一方，穿力暂停；但合走是暂停不是治愈。
8. **穿冲同现，互为放大**：原局有穿，运年再见冲，身体 / 精力问题当年集中爆发。
9. **穿破财库≠开库，是库破财漏**：双辰穿一戌不是开库，破财级别远大于冲开。

宫位与健康：年柱有穿 = 先天体质弱、幼年呼吸系统差；月柱 = 脾胃消化慢性问题；日柱 = 中年身体透支、肾 / 泌尿；时柱 = 晚年孤寂、子女拖累。

### 刑（变化引擎）

> 传统派视刑为官非，盲派视刑为变化引擎：刑得好的命局往往"折腾富"。

| 类型 | 组合 | 定性 |
|:---|:---|:---|
| 恃势之刑 | 寅巳申 | 折腾刑：每折腾一次上升一点，劳碌有功 |
| 无恩之刑 | 丑戌未 | 开库刑：三库同开，能量剧烈交换，力度大于单冲、风险更大 |
| 自刑 | 辰辰、午午、酉酉、亥亥 | 内耗刑：自己跟自己过不去，机会来了接不住 |

| 作用 | 现实翻译 | 吉凶 |
|:---|:---|:---|
| **刑开（有功）** | 资产重组、职位骤变、跨界转型、大额资金释放 | 刑开宾位财库得大利；刑开主位身库身体大病 |
| **刑伤（有灾）** | 纠纷缠身、官非诉讼、手术 | 伤体者凶，伤用者吉 |

铁则：
10. **三刑齐，必应大动**：原局两字，运年补齐第三字，当年必有剧变。刑的是"用"（财官杀）吉，刑的是"体"（日主 / 比劫 / 印 / 禄）凶。
11. **自刑看根不看干**：自刑在地支；日支自刑最凶，年时次之。自刑怕"激"（再逢冲刑），喜"泄"（食伤转化）。
12. **刑≠官非，刑 = 剧烈变化**：寅巳申 = 跨行业 / 跨地域折腾型成功，风险是到处得罪人；丑戌未 = 资源重组、资产置换型成功，风险是官司信用破产；自刑 = 自我加压型成功（艺术家 / 极限运动），风险是抑郁与决策瘫痪。

### 制尽与制不尽（效率定级）

> 不看日主旺衰，只看目标（财 / 官）是否被制尽。

| 目标状态 | 根型 | 最终强度 | 效率等级 | 财富量级 |
|:---|:---|:---:|:---|:---|
| 虚透无根（不在地支现身） | 无根 | 0% | **制尽（S 级）** | 亿级，大富 |
| **坐库根**（丙坐戌 / 壬坐辰） | 库根 | 60%×距离 | **制不尽但能压（A 级）** | 千万级，现金流不稳，"三年不开张开张吃三年" |
| 有生扶根 | 生扶根 | 80%×距离 | 制不尽（A/B 级） | 百万～千万 |
| 有本气根 | 本气根 | 100%×距离 | 制不尽（B/C 级） | 普通 |
| 体虚或被反制 | — | — | 效率低下（D 级） | 较差 |

- 目标原有微根却被旺局彻底熔化（根被铲除），效率反超 S 级，为"制尽中的极效"。
- 做功效率五级：S = 功神双现 + 目标被制尽 + 无破坏；A = 功神有力 + 目标被制 + 轻微破坏可化解；B = 功神有根 + 目标被制但不彻底；C = 功神虚浮 + 目标反制；D = 功神被合走 / 冲坏 + 目标无制。
- 层级速查：S 级 3 种以上手段 + 成势，亿元以上；A 级 2—3 种手段，千万级；B 级 1—2 种手段，百万级；C 级做功无效，工薪阶层。

### 食伤生财截断技法

同是"食伤生财"，富穷之别在链路通不通：

| 截断位置 | 程度 | 判断 |
|:---|:---:|:---|
| 印在食伤与财之间 | 致命 | 直接截断，食伤生不到财 |
| 印贴身克食伤（旁邻） | 严重 | 有才发挥不出 |
| 印远而食伤近财 | 轻微 | 影响有限，不算截断 |

打通逻辑：印克食伤（截断）→ 行财制印之运 = 堵点打开，反而发大财；食伤生财顺通 → 行印运 = 好局被截，从富转穷。

- **忌神链（负面）**：年干伤官 → 月干偏财 → 月支官杀，越生越旺、忌神激活。
- **伤官制杀（正面）**：伤官与官杀同支紧邻制约，有制杀潜质。
- 财富口诀：伤官 + 财星 = 靠技术才华赚钱；财星 + 官杀 = 赚钱伴随压力，财大压身。

## 第四阶段：时间引爆

**大运四原则**：
1. 出现为应：运年出现原局某字，该字被激活。
2. 合冲为变：合住或冲开原局某字，力量生变。
3. 空亡为应：流年填实空亡必应事。
4. 伏反为极：伏吟加倍，反吟颠覆。

**流年三重引动**（优先级）：填实 > 冲合大运 > 伏吟反吟。

| 触发条件 | 应事 |
|:---|:---|
| 流年地支冲某柱地支 | 该柱所主之事有变；原局有冲再来冲 = 冲上加冲，财富 / 压力同时到顶 |
| 流年地支合大运地支 | 合作、感情、牵绊加深 |
| 流年地支合日支 | 本人有机会 |
| 原局有合、运年来冲 | 合被冲开，协议 / 关系被撕开 |
| 原局有冲、运年来合 | 冲被合住，动荡减弱，事情暂停 |
| 流年填实空亡 | 该字代表的十神当年"突然真实发生"，吉凶兑现 |
| 伏吟（流年 = 日柱） | 本人身心动荡 |

流月应期：天干事件在地支月份兑现，地支事件在天干透出时兑现；冲合刑害引动原局某字为应期。大运引动某领域 = 该领域十年实质性变化。

## 第五阶段：取象输出

### 神煞（精选七煞）

> 神煞是颜色，十神才是骨肉：神煞不决定吉凶，只描述事件形态与应事时间。

| 神煞 | 查法 | 取象 | 应期与铁则 |
