# 双钱包会员与订阅体系设计

## 目标

以“免费体验 + 会员月度积分 + 永久点数包”统一全站会员、解读与元气 Agent 的消费规则。服务端是积分余额、咨询主题状态、扣款和退款的唯一权威；前端只展示服务端返回的数据。

## 产品规则

- 游客可使用称骨、星座、八字基础盘和通用黄历；塔罗限累计 4 次单牌体验。
- 深度报告、个性化黄历需要登录；新注册账号获得 10 点永久积分。
- 元气 Agent 是用户身边可连续追问的玄学顾问，而不是逐句售卖的问答框：游客可免费体验 1 个临时咨询主题、最多 5 轮；注册后可认领这个临时主题。
- 登录用户以 5 点开启一个咨询主题。每个主题最多 8 轮成功问答、有效 72 小时；同一主题会持续携带当前命盘、报告和日期上下文。
- 会员月度积分：凡者 ¥19.9 / 30 点，玄者 ¥59.9 / 100 点，天者 ¥129.9 / 260 点。
- 轻量解读 2 点，标准解读 5 点，元气 Agent 每开启一个成功的咨询主题 5 点；主题内追问不重复扣点。
- 月度积分于当前周期结束时清零；注册赠点与已购买点数永久有效。
- 扣款顺序固定为：先扣本周期月度积分，再扣永久积分。退款必须按照原扣款来源退回。
- 凡者及以上可使用个性化黄历每日提醒。真实支付接入前，会员和点数包都只展示购买入口，不会直接开通或加点。

## 数据模型与兼容

账号新增 `monthlyCreditsUsed`、`permanentCredits` 与最近一次扣款记录。读取旧账号时，将旧 `creditsUsed` 安全映射为月度已用额度，不丢弃历史余额；免费账号不再获得 100 月度积分。Agent 会话索引新增一个可选 `consultation` 字段，保存主题类型、剩余轮数、过期时间与原始扣款来源。

服务端对外返回月度可用、永久可用、合计可用与下一次月度清零时间。保留 `creditsUsed` 兼容旧页面，但其含义映射到月度已用额度。

## 页面体验

- 顶栏显示总可用点数。
- 个人中心展示“本月积分 / 永久积分 / 合计可用”，并说明先用即将到期的月度积分。
- 订阅弹层包含三张会员卡与四张永久点数包卡；每张卡重点显示点数、约可完成的标准解读数、Agent 咨询主题数与可追问轮数和有效期。
- 会员提供月付、季付、年付三种预览周期：季付约 95 折、年付约 83 折；月度积分仍按月发放并当月清零，避免把一次性长期订阅误解成永久积分。
- Agent 页在标题旁展示当前主题的剩余轮数和有效期；游客明确展示“免费体验 5 轮”，额度用尽后引导注册而非静默阻断。
- 价格与支付均为预览状态，避免在未接入支付回调前修改账号权益。

## 验证

测试覆盖：注册赠点、月度优先扣款、月度不足时永久补扣、退款按原来源恢复、月度到期清零且永久点不变、付费会员到期降为免费但永久点保留、游客塔罗四次限制；以及 Agent 游客五轮体验、登录主题首次成功扣点、八轮上限、72 小时到期、失败不扣点、主题续问不重复扣点和会员页面核心文案与价格。
