## 四、关键风险与备注

1. **两套 PLANS 分裂**是当前最大隐患：用户看到的「卖点」（20/200 次、精读文章）与真实权限（登录全开）不一致，易导致信任问题或返工。
2. `ReportLock` 引导文案统一写「注册即默认开通凡境」，但 Profile 三档并存、无到期——默认档位语义需要明确（是试用期？还是默认付费？）。
3. 塔罗抽牌页 `TarotReading.jsx`（解读页）与收藏、历史等数据均为本地全局存储，与账号无绑定——若做「云端命盘档案」需迁移。
4. 分享只读（游客可见）已实现，转发由后端短链承载（`server/`），属独立链路，与本模块无冲突。
